## Recoverable state

This repo is part of a recovery run from 2026-08-31. The sprint was triggered by a single costly line in eight outreach emails: "no formal research background in NLP." It was meant to say "no publications." It was read as "no NLP experience." The correction pattern is documented and reusable.

The sanity gate before anything else goes public: every README is checked against `career-ops/voice-dna.md` and run through the ikigai scorer. No claim goes public that is not traceable to a file on disk. The corpus has been burned three times by numbers that turned out to be grep artifacts, stale counts, or contaminated runs. That discipline is the point.
